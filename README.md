# ДронЛаб — БпЛА для «Основ національного спротиву»

Готовий навчальний комплект на одну пару (80 хв): тренажер-гра і презентація. Звичайний статичний сайт без збирання і без залежностей.

| Шлях | Що це |
|---|---|
| `/` (`index.html`) | **ДронЛаб**: 9 місій коду (студенти пишуть JavaScript для дрона), PID-лабораторія, ігри «Збери дрон», «Розпізнай БпЛА», бліц, звіт пілота |
| `/slides/` (`slides/index.html`) | **Презентація** на 26 слайдів. Керування: ← → або свайп, `F` — повний екран, `N` — нотатки викладача |
| `TEACHER_NOTES.md` | Хід заняття і нотатки до кожного слайда |

Прогрес студента зберігається лише в його браузері (localStorage). Наприкінці пари студент натискає «Звіт» і надсилає текст викладачеві.

## Локальний перегляд
Відкрийте `index.html` у браузері або запустіть `npx serve .`
